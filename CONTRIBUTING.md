# Contributing

Thank you for helping! Reports from other boiler models are the most valuable contribution: open an issue with the
model, the Dominus module version and what works or not.

## Pull requests

- Keep one topic per pull request and describe how you tested it (boiler model, Dominus module, integration version).
- Match the style of the surrounding code; new entity names need a translation key in all 11 language files.
