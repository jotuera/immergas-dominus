# Współtworzenie

[English](CONTRIBUTING.md) · **Polski**

Dziękuję za pomoc! Najcenniejsze są zgłoszenia z innych modeli kotłów: załóż zgłoszenie z modelem, wersją modułu
Dominus i tym, co działa, a co nie.

## Pull requesty

- Jeden temat na pull request i opis, jak to sprawdziłeś (model kotła, moduł Dominus, wersja integracji).
- Trzymaj się stylu otaczającego kodu; nowe nazwy encji potrzebują klucza tłumaczenia we wszystkich 11 plikach
  językowych.
