# Security

**English** · [Polski](SECURITY.pl.md)

The integration controls a boiler through the Dominus module. Please report a security problem **privately**, not in
a public issue: use GitHub's *Report a vulnerability* (the **Security** tab of this repository). You get an answer
within a few days.

Supported: the latest release. Good practice:
- the Dominus password stays in the Home Assistant config entry – do not paste it into issues or logs you share;
- keep the Dominus module on your local network (port 2000 is not meant for the internet);
- use one connection to the module at a time (Home Assistant or the app).
